TOPIC 1: PYTHON INTRODUCTION
------------------------------------------------------------

Q1. What is Python?

ANS:
Python is a high-level, interpreted, general-purpose
programming language. It is easy to read and understand.

Q2. What are the features of Python?

ANS:
1. Easy to learn
2. High-level language
3. Interpreted execution model
4. Dynamically typed
5. Object-oriented
6. Platform independent
7. Open-source
8. Large standard library

Q3. Why is Python called a high-level language?

ANS:
Because its syntax is close to human language and developers
do not need to manage low-level hardware operations directly.

Q4. Is Python compiled or interpreted?

ANS:
Python is commonly called an interpreted language.
In CPython, source code is first compiled into bytecode,
which is executed by the Python virtual machine.

Q5. What is an interpreter?

ANS:
An interpreter is a program that executes code.

Q6. Difference between compiler and interpreter?

ANS:
Compiler:
- Translates source code before execution.
- Commonly generates machine code or another target form.

Interpreter:
- Executes code through an execution environment.
- Runtime errors can occur during execution.

Q7. What is indentation?

ANS:
Indentation means spaces at the beginning of a line.
Python uses indentation to define code blocks.

Q8. What happens if indentation is incorrect?

ANS:
Python may raise IndentationError or another syntax error.

Q9. What are comments?

ANS:
Comments are notes in code that are ignored during
normal execution.

Example:
# This is a comment

Q10. What is PEP 8?

ANS:
PEP 8 is the Python style guide that defines coding
conventions and improves code readability.

Q11. Is Python case-sensitive?

ANS:
Yes. Name and name are treated as different identifiers.

Q12. What is the difference between input() and print()?

ANS:
input()  - Receives input from the user.
print()  - Displays output to the user.

Q13. What is the use of input()?

ANS:
It receives user input and returns it as a string.

Q14. What is the use of print()?

ANS:
It displays information on the screen.

TOPIC 2: VARIABLES AND CONSTANTS
------------------------------------------------------------

Q1. What is a variable?

ANS:
A variable is a name that refers to an object in memory.
It is used to store and access data.

Q2. How do you declare a variable?

ANS:
By assigning a value using the assignment operator.

Example:
x = 10

Q3. What are variable naming rules?

ANS:
1. Must start with a letter or underscore.
2. Cannot start with a number.
3. Can contain letters, numbers and underscores.
4. Spaces are not allowed.
5. Keywords cannot be used.
6. Names are case-sensitive.

Q4. What is multiple assignment?

ANS:
Assigning values to multiple variables in one statement.

Example:
a, b, c = 10, 20, 30

Q5. How do you assign the same value to multiple variables?

ANS:
a = b = c = 100

Q6. What is a constant?

ANS:
A constant is a value intended not to change.
Python does not strictly enforce constants.
Uppercase names are used by convention.

Example:
PI = 3.14

Q7. What is dynamic typing?

ANS:
Python determines the data type of an object at runtime.
A variable can refer to objects of different types.

Example:
x = 10
x = "Python"

Q8. What is type casting?

ANS:
Converting one data type into another.

Types:
1. Implicit type conversion
2. Explicit type conversion

Q9. Difference between implicit and explicit conversion?

ANS:
Implicit:
Python performs conversion automatically in supported
operations.

Explicit:
Developer manually converts using functions such as
int(), float(), str() and bool().

Q10. What is type()?

ANS:
Returns the exact type of an object.

Example:
print(type(10))

Output:
<class 'int'>

Q11. What is isinstance()?

ANS:
Checks whether an object belongs to a particular class
or its subclass.

Example:
print(isinstance(10, int))

Output:
True

Q12. Difference between type() and isinstance()?

ANS:
type()       - Checks exact type.
isinstance() - Checks class and subclass compatibility.

Q13. What is id()?

ANS:
Returns an object's identity, which remains constant
during the object's lifetime.

Q14. What are common type conversion functions?

ANS:
int()
float()
str()
bool()
list()
tuple()
set()
dict()
complex()

Q1. What are data types?

ANS:
Data types define the kind of value an object represents
and the operations that can be performed on it.

Q2. What are the main built-in data types?

ANS:

1. Numeric:
   int, float, complex

4. Sequence:

5. Set:
   set, frozenset

Q3. What is int?

ANS:

Q4. What is float?

Q5. What is complex?

ANS:
Stores real and imaginary numbers.
Python uses j for the imaginary part.

Example:
x = 5 + 3j

Q6. What is string?

ANS:
A sequence of characters enclosed in quotes.

Q7. What is Boolean?

ANS:
A data type that represents True or False.

Q8. What is NoneType?

ANS:

Q9. What are mutable data types?

ANS:
Objects whose contents can be modified after creation.

Examples:
list, dict, set, bytearray

Q10. What are immutable data types?

ANS:
Objects whose contents cannot be modified after creation.

Examples:
int, float, complex, str, tuple, bool,
frozenset, bytes

Q11. Difference between mutable and immutable?

ANS:
Mutable   - Can be modified after creation.
Immutable - Cannot be modified after creation.

Q12. Difference between list and tuple?

ANS:
List:
- Mutable
- Uses []
- Supports modification
- Allows duplicates

Tuple:
- Immutable
- Uses ()
- Does not support element reassignment
- Allows duplicates

Q13. Difference between set and frozenset?

ANS:
Set:
- Mutable
- Can add and remove elements

Frozenset:
- Immutable
- Cannot add or remove elements

Q14. Difference between list, tuple, set and dictionary?

ANS:
List:
Ordered, mutable, duplicates allowed.

Tuple:
Ordered, immutable, duplicates allowed.

Set:
No positional order, mutable, unique elements.

Dictionary:
Insertion ordered, mutable, key-value pairs,
unique keys.

Q15. Can a list contain different data types?

ANS:
Yes.

Example:

Q16. Can a tuple contain a list?

ANS:

can still be modified.

Q17. Can a dictionary have duplicate keys?

ANS:
No. Duplicate keys overwrite previous values.

Q18. What are truthy and falsy values?

ANS:
Truthy values evaluate to True in Boolean conditions.
Falsy values evaluate to False.

Common falsy values:
False, None, 0, 0.0, "", [], (), {}, set()

Q19. What are binary data types?

ANS:
bytes       - Immutable byte sequence.
bytearray   - Mutable byte sequence.
memoryview  - Accesses binary data without copying it.

Yes.

Q10. Can we use if without else?

ANS:
Yes. Else is optional.

Q11. What happens if multiple if statements are True?

ANS:

branch executes.

Q12. What are truthy and falsy conditions?

ANS:
Truthy values evaluate to True.
Falsy values evaluate to False.

TOPIC 6: LOOPS
------------------------------------------------------------

Q1. What is a loop?

ANS:
A loop repeatedly executes a block of code.

Q2. What are the types of loops?

ANS:
1. for loop
2. while loop
3. Nested loops

Q3. What is a for loop?

ANS:
Iterates over an iterable such as a list, tuple,
string or range.

Q4. What is a while loop?

ANS:
Executes repeatedly while the condition is True.

Q5. Difference between for and while?

ANS:
for:
- Iterates over an iterable.
- Commonly used to traverse sequences.

while:
- Runs based on a condition.
- Commonly used when repetitions depend on a condition.

Q6. What is a nested loop?

ANS:
A loop inside another loop.

Q7. What is an infinite loop?

ANS:
A loop that does not terminate because its stopping
condition is never reached.

Q8. What is range()?

ANS:
Generates a sequence of integers.

Syntax:
range(start, stop, step)

Q9. What are loop control statements?

ANS:
1. break
2. continue
3. pass

Q10. What is break?

ANS:
Immediately terminates the nearest enclosing loop.

Q11. What is continue?

ANS:
Skips the remaining statements in the current iteration
and moves to the next iteration.

Q12. What is pass?

ANS:
Does nothing. It is used as a placeholder.

Q13. Difference between break, continue and pass?

ANS:
break    - Exits the loop.
continue - Skips current iteration.
pass     - Does nothing.

Q14. Can we use else with loops?

ANS:
Yes. The else block executes when the loop finishes
normally, but not when it terminates using break.

Q15. What is enumerate()?

ANS:
Returns an index and corresponding value while iterating.

Q16. What is zip()?

ANS:
Combines multiple iterables element by element.
By default, stops at the shortest iterable.

Q17. Difference between range() and enumerate()?

ANS:
range() generates numbers.
enumerate() provides index and value.

Q12. What is disjoint?

Q13. What is frozenset?

TOPIC 12: COMPREHENSIONS
------------------------------------------------------------

Q1. What is comprehension?

ANS:
A concise way to create collections using expressions
and iteration.

Q2. What are the types?

ANS:
1. List comprehension
2. Dictionary comprehension
3. Set comprehension
4. Generator expression

Q3. What is list comprehension?

ANS:
Creates a list using a compact expression.

Example:
numbers = [1, 2, 3, 4]
result = [x * 2 for x in numbers]

OUTPUT:
[2, 4, 6, 8]

Q4. What is conditional list comprehension?

ANS:
A comprehension that filters values using an if condition.

Example:
[x for x in range(10) if x % 2 == 0]

Q5. What is dictionary comprehension?

ANS:
Creates dictionaries using an expression.

Example:
{x: x**2 for x in range(1, 4)}

OUTPUT:
{1: 1, 2: 4, 3: 9}

Q6. What is set comprehension?

ANS:
Creates a set using a comprehension expression.

Q7. What is generator expression?

ANS:
Creates a generator that produces values on demand.

Q8. Difference between list comprehension and generator?

ANS:
List comprehension:
- Uses []
- Creates the list immediately
- Stores all results in memory

Generator expression:
- Uses ()
- Produces values on demand
- Generally uses less memory

Q9. Practical: Increase elements by 10.

numbers = [10, 20, 30]

result = [x + 10 for x in numbers]

print(result)

OUTPUT:
[20, 30, 40]

TOPIC 20: SHALLOW COPY AND DEEP COPY

Q1. What is copying?

ANS:
Copying means creating another reference or object
based on an existing object.

Q2. What are the types of copying?

ANS:
1. Assignment
2. Shallow copy
3. Deep copy

Q3. What is assignment?

ANS:
Assignment creates another reference to the same object.
It does not create a copy.

Example:

b = a

b.append(30)

print(a)

OUTPUT:
[10, 20, 30]

Q4. What is shallow copy?

ANS:
Shallow copy creates a new outer object but references
the same nested objects.

Module:
copy

Method:
copy.copy()

Q5. What is deep copy?

ANS:
Deep copy creates a new outer object and recursively
copies nested objects.

Module:
copy

Method:
copy.deepcopy()

Q6. Difference between shallow and deep copy?

ANS:

Shallow copy:
- New outer object.
- Nested objects are shared.
- Nested modifications can affect original.

Deep copy:
- New outer object.
- Nested objects are copied recursively.
- Nested modifications do not affect original.

Q7. Practical example:

shallow = copy.copy(original)
deep = copy.deepcopy(original)

shallow[0][0] = 100
deep[1][0] = 999

print("Original:", original)
print("Shallow:", shallow)
print("Deep:", deep)

OUTPUT:

Original: [[100, 20], [30, 40]]
Shallow:  [[100, 20], [30, 40]]
Deep:     [[10, 20], [999, 40]]

Q8. What is the difference between copy.copy()
and copy.deepcopy()?

ANS:
copy.copy() creates a shallow copy.
copy.deepcopy() creates a deep copy.

Example: Execution time decorator

    import time
    from functools import wraps

    def timer(func):

        @wraps(func)
        def wrapper(*args, **kwargs):

            start = time.perf_counter()

            result = func(*args, **kwargs)

            end = time.perf_counter()

            print("Execution time:", end - start)

            return result

        return wrapper

    @timer
    def calculate():
        return sum(range(100000))

    calculate()
