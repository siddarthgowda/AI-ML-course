Q1. What is file handling in Python?

Ans: File handling is the process of creating, opening,
reading, writing, updating and deleting files using Python.

Example program:

```python
from pathlib import Path

folder = Path("file_demo")
folder.mkdir(exist_ok=True)
notes = folder / "students.txt"

notes.write_text("Rahul\nPriya\nAmit\n")
print(notes.read_text())
notes.unlink()
print("deleted:", not notes.exists())
```

Q2. Why do we use file handling?

Ans:
- To store data permanently.
- To retrieve stored information.
- To read and write files.
- To manage external data.
- To process large datasets.

Example program:

```python
from pathlib import Path

path = Path("file_demo/marks.txt")
path.parent.mkdir(exist_ok=True)
path.write_text("Math 80\nPython 95\n")
print("saved, then read back:")
print(path.read_text())
```

Ans:
Text File:
- Stores characters.
- Human-readable.
- Uses text modes.
- Example: .txt

Binary File:

- Not directly human-readable.
- Uses binary modes.
- Example: .jpg

Example program:

Q7. What is open()?

Ans: open() is a built-in Python function used to open files.

Syntax:

Example program:

```python

```

Q8. What are the arguments of open()?

Ans:
open(file, mode, buffering, encoding, errors, newline)

- file: File name or path.
- mode: Opening mode.
- buffering: Buffering policy.
- encoding: Character encoding.
- errors: Encoding error handling.
- newline: Newline handling.

Example program:

```python
from pathlib import Path

Path("file_demo").mkdir(exist_ok=True)
file = open(
    "file_demo/args.txt",
    mode="w",
    buffering=1,
    encoding="utf-8",
    errors="strict",
    newline="\n",
)
file.write("name,city\nAmit,Bengaluru\n")
file.close()
print(Path("file_demo/args.txt").read_text(encoding="utf-8"))
```

Q13. What are the different file opening modes?

Ans:

r   = Read
w   = Write
a   = Append
x   = Exclusive creation
r+  = Read and Write
w+  = Write and Read
a+  = Append and Read

rb  = Read Binary
wb  = Write Binary
ab  = Append Binary

rb+ = Read and Write Binary
wb+ = Write and Read Binary
ab+ = Append and Read Binary

Example program:

```python
from pathlib import Path

folder = Path("file_demo")
folder.mkdir(exist_ok=True)
path = folder / "modes.txt"
path.write_text("old\n")

with path.open("r") as file:
    print("r :", file.read().strip())
with path.open("a") as file:
    file.write("added\n")
print("after a:", path.read_text().replace("\n", " | "))
with path.open("w") as file:
    file.write("replaced\n")
print("after w:", path.read_text().strip())
```

Q17. What is x mode?

- Raises FileExistsError if file already exists.



Q41. What is a file pointer?

Ans: A file pointer represents the current position in a file
where the next read or write operation occurs.

Example program:

```python
from pathlib import Path

path = Path("file_demo/pointer.txt")
path.parent.mkdir(exist_ok=True)
path.write_text("PYTHON")
with path.open() as file:
    print("start", file.tell())
    print(file.read(2))
    print("after two characters", file.tell())
```

Q45. What does seek(0) do?

Ans: Moves the file pointer to the beginning.

Example program:

```python

path = Path("file_demo/seek_zero.txt")

```

Q46. What are the arguments of seek()?

Ans:
file.seek(offset, whence)

whence:
0 = Beginning of file.
1 = Current position.
2 = End of file.

Note: Arbitrary relative seeking is restricted in text mode.
Binary mode supports byte-based relative seeking.

Example program:

```python
from pathlib import Path

path = Path("file_demo/seek_args.bin")
path.parent.mkdir(exist_ok=True)
path.write_bytes(b"ABCDEFGH")
with path.open("rb") as file:
    file.seek(2, 0)
    print("from start :", file.read(1))
    file.seek(1, 1)
    print("from current:", file.read(1))
    file.seek(-1, 2)
    print("from end   :", file.read(1))
```

Q47. What is truncate()?

Ans: Reduces the file size to a specified number of bytes.
If no size is provided, it truncates at the current position.

Example program:

```python
path.parent.mkdir(exist_ok=True)

with path.open("r+") as file:
    file.truncate(5)
print(repr(path.read_text()))
```

Example program:

Q213. CUSTOM JSON ENCODER

```python
import json
from datetime import datetime

class MyEncoder(json.JSONEncoder):
    def default(self, obj):
        if isinstance(obj, datetime):
            return obj.isoformat()
        return super().default(obj)

data = {"date": datetime(2026, 11, 5, 9, 0, 0)}
print(json.dumps(data, cls=MyEncoder))
```

Q216. WHAT IS PICKLE
Ans:
Pickle is a Python module used to serialize and
deserialize Python objects.

Serialization:
    Python object -> Byte stream.

Deserialization:
    Byte stream -> Python object.

Import:

    import pickle

Example program:

```python
import pickle

blob = pickle.dumps({"name": "John"})
print(pickle.loads(blob))
```

Q217. PICKLE FUNCTIONS
Ans:
pickle.dump()
        Writes an object into a binary file.

    pickle.dumps()
        Converts object into bytes.

    pickle.load()
        Reads object from a binary file.

    pickle.loads()
        Converts bytes into a Python object.

Example program:

```python
import pickle
from pathlib import Path

path = Path("file_demo/funcs.pkl")
path.parent.mkdir(exist_ok=True)
blob = pickle.dumps([1, 2, 3])
path.write_bytes(pickle.dumps([1, 2, 3]))
print(pickle.loads(blob))
print(pickle.loads(path.read_bytes()))
```

Q219. PICKLE VS JSON
Ans:
Pickle:
    Python-specific.
    Supports many Python objects.
    Binary format.
    Not safe for untrusted files.

JSON:
    Language-independent.
    Supports limited standard data types.
    Text format.
    Suitable for APIs.

IMPORTANT SECURITY:
    Never unpickle untrusted or unknown files.
    Malicious pickle data can execute arbitrary code.

Example program:


Q226. SEARCHING FILES
Ans:
Path(".").glob("*.csv")

    Path(".").rglob("*.csv")

glob:
    Searches matching paths in a directory.

rglob:
    Searches recursively through subdirectories.

Example program:

```python
from pathlib import Path

folder = Path("file_demo/search")
(folder / "sub").mkdir(parents=True, exist_ok=True)
(folder / "a.csv").write_text("a")
(folder / "b.txt").write_text("b")
(folder / "sub" / "c.csv").write_text("c")
print(sorted(p.name for p in folder.glob("*.csv")))
print(sorted(p.name for p in folder.rglob("*.csv")))
```
