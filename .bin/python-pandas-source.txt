PART 1: PANDAS STUDY NOTES
------------------------------------------------------------

Q1. WHAT IS PANDAS
Ans:
Pandas is a Python library used for data manipulation,
data cleaning, and data analysis.

It is commonly used for:
    - CSV files
    - Excel files
    - JSON data
    - Data cleaning
    - Filtering and sorting
    - Grouping and aggregation
    - Data analysis
    - Preparing datasets for machine learning

Import:

    import pandas as pd

Main data structures:

    1. Series
    2. DataFrame

Q2. SERIES
Ans:
A Series is a one-dimensional labeled data structure.

Example:

    import pandas as pd

    s = pd.Series([10, 20, 30, 40])

Output:

    0    10
    1    20
    2    30
    3    40

Custom index:

    s = pd.Series(
        [90, 80, 70],
        index=["A", "B", "C"]
    )

Access:

    s[0]
    s["A"]

Important properties:

    s.index
    s.values
    s.dtype
    s.shape
    s.size
    s.ndim
    s.name

Q3. DATAFRAME
Ans:
A DataFrame is a two-dimensional table containing
rows and columns.

Example:

    data = {
        "Name": ["Amit", "Ravi", "John"],
        "Age": [25, 30, 28],
        "Salary": [30000, 40000, 35000]
    }

    df = pd.DataFrame(data)

Output:

       Name  Age  Salary
    0  Amit   25   30000
    1  Ravi   30   40000
    2  John   28   35000

Important properties:

    df.shape
    df.size
    df.ndim
    df.columns
    df.index
    df.dtypes
    df.values
    df.T
    df.empty

Q8. SELECTING COLUMNS
Ans:
Select one column:

    df["Name"]

Select multiple columns:

    df[["Name", "Age"]]

Select rows:

    df[0:3]

Select a column as a Series:

    df["Age"]

Select a single-column DataFrame:

Q9. LOC AND ILOC
Ans:
loc:
    Label-based selection.

iloc:
    Integer-position-based selection.

Examples:

    df.loc[0]
    df.loc[0, "Name"]
    df.loc[:, "Name"]
    df.loc[0:2, ["Name", "Age"]]

    df.iloc[0]
    df.iloc[0, 1]
    df.iloc[:, 0]
    df.iloc[0:2, 0:2]

Important:
    loc slicing includes the ending label when applicable.
    iloc slicing excludes the ending position.

Q10. FILTERING DATA
Ans:
Single condition:

    df[df["Age"] > 25]

Multiple conditions:

    df[
        (df["Age"] > 25) &
        (df["Salary"] > 30000)
    ]

OR condition:

    df[
        (df["Age"] < 25) |
        (df["Salary"] > 35000)
    ]

NOT condition:

    df[~(df["Age"] > 25)]

isin:

    df[df["Name"].isin(["Amit", "Ravi"])]

between:

    df[df["Age"].between(20, 30)]

query:

    df.query("Age > 25")

Q15. MISSING VALUES
Ans:
Missing values can appear as:
    NaN
    None
    NaT

Check missing values:

    df.isnull()
    df.isna()
    df.notnull()
    df.notna()

Count missing values:

    df.isnull().sum()

Remove missing rows:

    df.dropna()

Remove rows where all values are missing:

    df.dropna(how="all")

Fill missing values:

    df.fillna(0)

Fill one column:

    df["Age"] = df["Age"].fillna(
        df["Age"].mean()
    )

Other filling methods:

    df.ffill()
    df.bfill()

ffill:
    Uses previous valid value.

bfill:
    Uses next valid value.

Q16. APPLY, MAP AND APPLYMAP
Ans:
map():
    Used mainly on Series to transform values.

    df["Name"].map(str.upper)

apply():
    Applies a function to a Series or DataFrame axis.

    df["Salary"].apply(lambda x: x * 2)

    df.apply(sum, axis=0)

applymap():
    Older DataFrame-wide element-wise function.
    Deprecated in modern Pandas.

    Prefer df.map() for element-wise DataFrame mapping
    in versions that support it.

Q17. GROUPBY
Ans:
Groupby is used to group records and calculate summaries.

Example:

    df.groupby("Department")["Salary"].mean()

Other operations:

    df.groupby("Department").sum()
    df.groupby("Department").count()
    df.groupby("Department").max()
    df.groupby("Department").min()
    df.groupby("Department").size()

Multiple aggregations:

    df.groupby("Department").agg({
        "Salary": ["sum", "mean", "max"],
        "Age": ["min", "max"]
    })

Q19. CONCAT, MERGE AND JOIN
Ans:
concat:
    Combines DataFrames along rows or columns.

    pd.concat([df1, df2], axis=0)

    pd.concat([df1, df2], axis=1)

merge:
    Combines DataFrames using common columns or keys.

    pd.merge(
        df1,
        df2,
        on="ID",
        how="inner"
    )

join:
    Commonly joins DataFrames using indexes.

    df1.join(df2)

Types of joins:

    inner:
        Only matching records.

    left:
        All left records and matching right records.

    right:
        All right records and matching left records.

    outer:
        All records from both sides.

Q25. CROSSTAB AND CUT
Ans:
crosstab:
    Creates frequency tables.

    pd.crosstab(
        df["Gender"],
        df["Department"]
    )

cut:
    Divides continuous values into intervals.

    pd.cut(
        df["Age"],

qcut:
    Divides data into quantile-based groups.

    pd.qcut(df["Salary"], q=4)
