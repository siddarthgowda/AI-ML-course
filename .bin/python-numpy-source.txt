Q1. What is NumPy?
Ans: NumPy stands for Numerical Python. It is a Python library used
for numerical calculations, mathematical operations and working
with multidimensional arrays.

Q2. Why do we use NumPy?
Ans:
- Faster numerical calculations.
- Efficient memory management.
- Multidimensional array support.
- Mathematical and statistical operations.
- Matrix and linear algebra operations.
- Useful for Data Science and Machine Learning.

Q3. What is the full form of NumPy?
Ans: Numerical Python.

Q4. How do you install NumPy?
Ans:
pip install numpy

Q5. How do you import NumPy?
Ans:
import numpy as np

Q6. Why do we use np?
Ans: np is an alias for NumPy. It makes accessing NumPy functions
easier.

Q7. What is ndarray?
Ans: ndarray means N-dimensional array. It is the main data
structure in NumPy.

Q8. Difference between Python list and NumPy array?

Python List:
- Built into Python.
- Can store different data types.
- General-purpose data structure.
- Multiplication by a number repeats the list.
- Generally slower for large numerical operations.

NumPy Array:
- Requires NumPy.
- Usually stores elements using one data type.
- Designed for numerical operations.
- Supports element-wise mathematical operations.
- Generally faster for large numerical operations.

Q9. Is NumPy written in Python?
Ans: NumPy provides a Python interface, but many computational
operations are implemented in compiled languages such as C.

Q10. Is NumPy mutable?
Ans: Yes. NumPy arrays are mutable. We can modify their elements.

Example:
a = np.array([10, 20, 30])
a[0] = 100
print(a)

Output:
[100  20  30]

Q11. Can NumPy store strings?
Ans: Yes. NumPy supports string arrays.

Q12. Can NumPy store mixed data types?
Ans: Yes. NumPy generally converts values into a common compatible
data type. Object arrays can also store mixed Python objects.

Q13. What is vectorization?
Ans: Vectorization means performing operations on entire arrays
without explicitly writing Python loops.

Example:
a = np.array([1, 2, 3])
print(a * 2)

Output:
[2 4 6]

Q14. Difference between NumPy and Pandas?

NumPy:
- Works mainly with arrays.
- Numerical calculations.
- Main object is ndarray.

Pandas:
- Works with Series and DataFrames.
- Data manipulation and analysis.
- Supports different data types across columns.

Q15. What is the relationship between NumPy and Machine Learning?
Ans: NumPy is used for numerical calculations, matrix operations,
data preprocessing and mathematical computations in Machine Learning.

Q16. What are the different dimensions in NumPy?

0D = Scalar
1D = Single-dimensional array
2D = Rows and columns
3D = Collection of 2D arrays

Q17. What is a 0D array?
Ans: An array containing a single scalar value.

a = np.array(10)
print(a.ndim)

Output:
0

Q18. What is a 1D array?
Ans: An array containing elements along one axis.

a = np.array([10, 20, 30])
print(a.ndim)

Output:
1

Q19. What is a 2D array?
Ans: An array containing rows and columns.

a = np.array([[10, 20], [30, 40]])

Ans: An array containing multiple 2D arrays.

Example:

11. BROADCASTING
======================================================================

Q131. What is broadcasting?
Ans: Allows operations between arrays of different shapes
when their dimensions are compatible.

Q132. Why do we use broadcasting?
Ans:
- Avoids manually repeating values.
- Makes calculations easier.
- Reduces unnecessary memory usage.
- Supports efficient operations.

Q133. What are broadcasting rules?

1. Compare dimensions from right to left.
2. Dimensions must be equal or one must be 1.
3. Missing dimensions are treated as 1.

Q134. Can arrays of different shapes be added?
Ans: Yes, if broadcasting rules are satisfied.

Q135. What happens when broadcasting rules fail?
Ans: NumPy raises ValueError.

Q136. Difference between broadcasting and vectorization?

Broadcasting = Handles compatible array shapes.
Vectorization = Performs operations on entire arrays.

Q316. BROADCASTING
Ans:
Broadcasting allows NumPy to perform operations
on arrays with different but compatible shapes.

Example:

    arr = np.array([10, 20, 30])

    arr + 5

Output:
    [15 25 35]

2D broadcasting:

    arr = np.array([[1, 2, 3],
                    [4, 5, 6]])

    arr + np.array([10, 20, 30])

Output:
    [[11 22 33]
     [14 25 36]]

Broadcasting rules:

Compare dimensions from right to left.

Dimensions are compatible if:
    1. They are equal.
    2. One of them is 1.
    3. One dimension is missing and treated as 1.

Otherwise, broadcasting raises ValueError.

Q319. AXIS IN NUMPY
Ans:
Axis determines the direction of an operation.

    arr = np.array([[1, 2, 3],
                    [4, 5, 6]])

    np.sum(arr, axis=0)

Output:
    [5 7 9]

axis=0:
    Operation down the rows, producing column results.

    np.sum(arr, axis=1)

Output:
    [6 15]

axis=1:
    Operation across columns, producing row results.

Q324. COPYING AND VIEWS
Ans:
View:
    Shares the underlying data when possible.

Copy:
    Creates independent data.

    arr.copy()

Basic slicing generally returns a view.

Fancy indexing generally returns a copy.

Example:

    arr = np.array([10, 20, 30])

    view = arr[1:]
    copy = arr[[1, 2]]

    view[0] = 99

    # Original array may change because view shares data.

    copy[0] = 88

    # Original array remains unchanged.
