Part 1: Basic File Handling

Q1 What is file handling in Python?

File handling means using Python to work with files on disk:

open them, read or write data, append, and close (or release)

them safely.

In interviews, mention the usual flow: open() → read/write →

close(), or with open(...) so the file closes automatically.

| Step | What happens |

|------|----------------|

| Create / open | open(path, mode) or Path.write_text() |

| Read / write | read(), write(), etc. |

| Close | close() or exit with block |

Example program:

from pathlib import Path

folder = Path("file_demo")
folder.mkdir(exist_ok=True)
notes = folder / "students.txt"

notes.write_text("Rahul\nPriya\nAmit\n")
print(notes.read_text())
notes.unlink()
print("deleted:", not notes.exists())

Q2 Why do we use file handling?

Variables and lists live only in RAM. When the program or

notebook kernel stops, that data is gone.

Files solve that:

  • **Permanent storage** — sales, student names, model output, logs.
  • **Share data** — CSV/JSON between Python, Excel, web apps.
  • **Big data** — read line-by-line instead of loading everything
  • into memory.

**Interview line:** “We use file handling when data must survive

after the program ends or must be exchanged with other systems.”

Example program:

from pathlib import Path

path = Path("file_demo/marks.txt")
path.parent.mkdir(exist_ok=True)
path.write_text("Math 80\nPython 95\n")
print("saved, then read back:")
print(path.read_text())

Q3 What are the two main types of files?

  • Text files
  • Binary files

Example program:

from pathlib import Path

folder = Path("file_demo")
folder.mkdir(exist_ok=True)
text_file = folder / "notes.txt"
binary_file = folder / "pixels.bin"
text_file.write_text("Hello Python\n")
binary_file.write_bytes(bytes([0, 255, 10, 20]))
print("text :", text_file.read_text())

Q4 What is a text file?

A text file stores data in human-readable character format.

Examples:

.txt, .csv, .py, .json, .xml, .html

Example program:

from pathlib import Path

path = Path("file_demo/report.txt")
path.parent.mkdir(exist_ok=True)
path.write_text("Name,Score\nAmit,90\n")
print(path.read_text())

Q5 What is a binary file?

A binary file stores information in bytes and is not

normally human-readable.

Examples:

.jpg, .png, .mp3, .mp4, .pdf, .exe

Example program:

from pathlib import Path

path = Path("file_demo/photo.bin")
path.parent.mkdir(exist_ok=True)
path.write_bytes(b"\x89PNG\r\n\x1a\n")
print(path.read_bytes())

Q6 Difference between text and binary files?

Text File:

  • Stores characters.
  • Human-readable.
  • Uses text modes.
  • Example: .txt

Binary File:

  • Stores bytes.
  • Not directly human-readable.
  • Uses binary modes.
  • Example: .jpg

Example program:

from pathlib import Path

folder = Path("file_demo")
folder.mkdir(exist_ok=True)
text_file = folder / "hello.txt"
binary_file = folder / "hello.bin"
text_file.write_text("Hello")
binary_file.write_bytes(b"Hello")
print(type(text_file.read_text()), text_file.read_text())
print(type(binary_file.read_bytes()), binary_file.read_bytes())

Q7 What is open()?

**open()** is the built-in function that connects your program

to a file on disk and returns a **file object**.

Syntax: file = open("data.txt", "r")

Better style: with open("data.txt", "r") as file: — closes

automatically even if an error occurs.

Always match **mode** to the job: r read, w overwrite,

a append (Tekbind trio).

Example program:

from pathlib import Path

Path("file_demo").mkdir(exist_ok=True)
file = open("file_demo/open_demo.txt", "w")
file.write("opened with open()\n")
file.close()
file = open("file_demo/open_demo.txt", "r")
print(file.read())
file.close()

Q8 What are the arguments of open()?

open(file, mode, buffering, encoding, errors, newline)

  • file: File name or path.
  • mode: Opening mode.
  • buffering: Buffering policy.
  • encoding: Character encoding.
  • errors: Encoding error handling.
  • newline: Newline handling.

Example program:

from pathlib import Path

Path("file_demo").mkdir(exist_ok=True)
file = open(
    "file_demo/args.txt",
    mode="w",
    buffering=1,
    encoding="utf-8",
    errors="strict",
    newline="\n",
)
file.write("name,city\nAmit,Bengaluru\n")
file.close()
print(Path("file_demo/args.txt").read_text(encoding="utf-8"))

Q9 What is a file object?

A file object is an object returned by open().

It provides methods to read, write and manage files.

Example program:

from pathlib import Path

Path("file_demo").mkdir(exist_ok=True)
file = open("file_demo/object.txt", "w+")
print(type(file).__name__)
file.write("file object\n")
file.seek(0)
print(file.read())
print("name:", file.name)
print("mode:", file.mode)
file.close()

Q10 What is the default file opening mode?

**r (read).** So open("data.txt") is the same as

open("data.txt", "r").

Implication: the file must **exist** and you **cannot write**

with default mode — common mistake in beginners’ code.

Example program:

from pathlib import Path

path = Path("file_demo/default_mode.txt")
path.parent.mkdir(exist_ok=True)
path.write_text("already here\n")
file = open(path)  # mode defaults to "r"
print("mode:", file.mode)
print(file.read())
file.close()

Q11 What happens if a file does not exist in read mode?

Python raises **FileNotFoundError** — a subclass of OSError.

Fix options:

  • Create first with w / a / x, or check with

Path(path).exists().

  • Use **try / except FileNotFoundError** for user-friendly
  • messages (see Part 6 in these notes).

Example program:

try:
    open("file_demo/missing_student.txt", "r")
except FileNotFoundError as error:
    print(type(error).__name__)
    print(error)

Q12 Can Python create files automatically?

Yes — you do **not** need a separate “create file” command.

| Mode | Creates if missing? |

|------|---------------------|

| w | Yes (then writes; truncates if existed) |

| a | Yes (append) |

| x | Yes only when path is free |

| r | **No** — error if missing |

Parent folders are **not** always created; use

Path("folder").mkdir(parents=True, exist_ok=True) or

os.makedirs when needed.

Example program:

from pathlib import Path

Path("file_demo").mkdir(exist_ok=True)
Path("file_demo/auto_new.txt").unlink(missing_ok=True)
file = open("file_demo/auto_new.txt", "w")
file.write("created because mode is w\n")
file.close()
print(Path("file_demo/auto_new.txt").read_text())

Part 2: File Opening Modes

Q13 What are the different file opening modes?

The **mode** string tells Python what you are allowed to do and

what happens if the file is missing.

**Text modes (class + interviews):**

| Mode | Read | Write | File missing | Existing file |

|------|------|-------|--------------|---------------|

| r | Yes | No | Error | Unchanged |

| w | No | Yes | Created | **Emptied** |

| a | No | Yes (end) | Created | Kept; append |

| x | No | Yes | Created | **Error** if exists |

| r+ | Yes | Yes | Error | Unchanged |

| w+ | Yes | Yes | Created | **Emptied** |

| a+ | Yes | Yes (end) | Created | Kept; append |

**Binary modes** — same idea with b (e.g. rb, wb, ab,

rb+, …). Use for images, pickle, non-text bytes.

**Memory trick:** r = read only, w = wipe and write,

a = add at end, x = exclusive create.

Example program:

from pathlib import Path

folder = Path("file_demo")
folder.mkdir(exist_ok=True)
path = folder / "modes.txt"
path.write_text("old\n")

with path.open("r") as file:
    print("r :", file.read().strip())
with path.open("a") as file:
    file.write("added\n")
print("after a:", path.read_text().replace("\n", " | "))
with path.open("w") as file:
    file.write("replaced\n")
print("after w:", path.read_text().strip())

Q14 What is r mode?

**r = read-only.** Default mode when you write open("f.txt").

  • File **must exist** or you get **FileNotFoundError**.
  • You cannot write; doing so raises **UnsupportedOperation** (or
  • similar on the file object).
  • Content on disk is **not** changed.
  • Pointer starts at the **beginning** of the file.

Example program:

from pathlib import Path

path = Path("file_demo/read_only.txt")
path.parent.mkdir(exist_ok=True)
path.write_text("Rahul\nPriya\n")
with path.open("r") as file:
    print(file.read())

Q15 What is w mode?

**w = write (truncate).** This is what Tekbind used for “save

new list to file”.

  • Creates the file if it does not exist.
  • If the file **already exists**, opening with w **deletes all
  • old content** first — then you write fresh data.
  • **Danger:** open("students.txt", "w") wipes previous names.

Use **a** to add without deleting, or **x** if the file must

  • not exist yet.

Example program:

from pathlib import Path

path = Path("file_demo/write_mode.txt")
path.parent.mkdir(exist_ok=True)
path.write_text("Rahul\nPriya\n")
with path.open("w") as file:
    file.write("Mary\nTom\n")
print(path.read_text())

Q16 What is a mode?

**a = append.** Class used this for “Good morning” at the end

without erasing earlier lines.

  • New write() data goes **only at the end** of the file.
  • Existing content **stays**.
  • Creates the file if missing.
  • Pointer is positioned at **end** when opened (good for logs).

Example program:

from pathlib import Path

path = Path("file_demo/append_mode.txt")
path.parent.mkdir(exist_ok=True)
path.write_text("Hello Python\n")
with path.open("a") as file:
    file.write("Good morning\n")
print(path.read_text())

Q17 What is x mode?

**x = exclusive creation** (“create only if the file does not

exist yet”).

| Point | Meaning |

|-------|---------|

| Creates | New empty file, like w |

| If file already exists | Raises **FileExistsError** (does not overwrite) |

| Pointer | Starts at the beginning (position 0) |

| Use when | You must not accidentally destroy existing data (config, lock file, one-time export) |

**w vs x (common interview):** w overwrites or creates;

x creates only when the path is free — safer when overwriting

would be a bug.

**Tekbind class:** Not taught; class used r, w, a only.

Example program:

from pathlib import Path

path = Path("file_demo/exclusive.txt")
path.parent.mkdir(exist_ok=True)
path.unlink(missing_ok=True)
with path.open("x") as file:
    file.write("created only once\n")
print("first:", path.read_text().strip())
try:
    path.open("x").close()
except FileExistsError as error:
    print(type(error).__name__)

Q18 What is r+ mode?

**r+ = read and write on an existing file** (both allowed on the

same open file).

| Point | Meaning |

|-------|---------|

| File must exist | Otherwise **FileNotFoundError** (unlike w+ / a+) |

| On open | **Does not** erase old content (unlike w+) |

| Default position | Start of file (0) — good for read-then-patch |

| Writing | Overwrites from current pointer unless you seek() |

**Compare modes (interview):**

  • **r+** — update existing file; keep content.
  • **w+** — create or **truncate** (empty file), then read/write.
  • **a+** — read anywhere, but **new writes** go to the **end**.

After read(), call file.seek(0) (or the right offset) before

write() — otherwise you append after the bytes you just read.

Example program:

from pathlib import Path

path = Path("file_demo/read_write.txt")
path.parent.mkdir(exist_ok=True)
path.write_text("Hello")
with path.open("r+") as file:
    print("before:", file.read())
    file.seek(0)
    file.write("Hi!!!")
print("after :", path.read_text())

Q19 What is w+ mode?

**w+ = read and write, but open behaves like w.**

  • Creates file if missing.
  • If file **exists**, content is **cleared on open** (truncate).
  • After writing, seek(0) then read() to see what you wrote.
  • Use when you want a **brand-new or reset** file and may read
  • back in the same session — not for “edit existing without
  • deleting”.

Example program:

from pathlib import Path

path = Path("file_demo/write_plus.txt")
path.parent.mkdir(exist_ok=True)
path.write_text("old content")
with path.open("w+") as file:
    file.write("new content")
    file.seek(0)
    print(file.read())

Q20 What is a+ mode?

**a+ = read anywhere, append on write.**

  • Creates file if missing; **keeps** old data.
  • read() / seek(0) can read from the start.
  • **write() still appends at the end** (not at current pointer
  • like r+).
  • Typical use: log file — read history, add a new line at bottom.

**Quick pick:** update middle of file → r+ with seek(); log

→ a or a+; replace whole file → w or w+.

Example program:

from pathlib import Path

path = Path("file_demo/append_plus.txt")
path.parent.mkdir(exist_ok=True)
path.write_text("Hello")
with path.open("a+") as file:
    file.write(" Python")
    file.seek(0)
    print(file.read())

Q21 Difference between w and a?

w = Overwrites existing content.
a = Adds content at the end.

Example program:

from pathlib import Path

folder = Path("file_demo")

Q22 Difference between r and r+?

r = Read only.
r+ = Read and write.

Example program:

from pathlib import Path

path = Path("file_demo/r_vs_rplus.txt")

w+ = Deletes old content.

a+ = Preserves old content and appends new content.

from pathlib import Path

folder = Path("file_demo")

Q24 What is binary mode?

Binary mode reads and writes data as bytes.

Example:
file = open("image.jpg", "rb")

Example program:

from pathlib import Path

path = Path("file_demo/image.bin")
path.parent.mkdir(exist_ok=True)
path.write_bytes(b"\x00\x01\x02\xff")
with path.open("rb") as file:
    data = file.read()
print(data)
print(list(data))

Q25 Can read() be used with binary files?

Yes. It returns bytes instead of strings.

Example program:

from pathlib import Path

path = Path("file_demo/sample.bin")
path.parent.mkdir(exist_ok=True)
