3 Variables

Definition: A variable is a name that refers to a value or object in a program. You can assign a value to a variable and use that name later.

### Naming rules

  • Must start with a letter or _. Cannot start with a number.
  • Cannot contain spaces.
  • Can contain letters, numbers, and underscores.
  • Python keywords such as if, else, and for cannot be used as names.
  • Python is case-sensitive, so age and Age are different names.

print is a built-in function, not a keyword. Avoid using print as a variable name because it hides the built-in function.
