Q1 WHAT IS PANDAS

Pandas is a Python library used for data manipulation,

data cleaning, and data analysis.

It is commonly used for:

  • CSV files
  • Excel files
  • JSON data
  • Data cleaning
  • Filtering and sorting
  • Grouping and aggregation
  • Data analysis
  • Preparing datasets for machine learning

Import:

import pandas as pd

Main data structures:

  • Series
  • DataFrame

Q2 SERIES

A Series is a one-dimensional labeled data structure.

Example:

import pandas as pd
s = pd.Series([10, 20, 30, 40])

Output:

0 10

1 20

2 30

3 40

Custom index:

s = pd.Series(
        [90, 80, 70],
        index=["A", "B", "C"]
    )

Access:

s[0]

s["A"]

Important properties:

s.index

s.values

s.dtype

s.shape

s.size

s.ndim

s.name

Q3 DATAFRAME

A DataFrame is a two-dimensional table containing

rows and columns.

Example:

data = {

"Name": ["Amit", "Ravi", "John"],

"Age": [25, 30, 28],

"Salary": [30000, 40000, 35000]

}

df = pd.DataFrame(data)

Output:

Name Age Salary

0 Amit 25 30000

1 Ravi 30 40000

2 John 28 35000

Important properties:

df.shape

df.size

df.ndim

df.columns

df.index

df.dtypes

df.values

df.T

df.empty

Q4 CREATING DATAFRAMES

From dictionary:

df = pd.DataFrame({

"Name": ["A", "B"],

"Age": [20, 25]

})

From list:

df = pd.DataFrame([

["A", 20],

["B", 25]

], columns=["Name", "Age"])

From NumPy array:

arr = np.array([[1, 2], [3, 4]])
df = pd.DataFrame(
        arr,
        columns=["A", "B"]
    )

From list of dictionaries:

df = pd.DataFrame([

{"Name": "A", "Age": 20},

{"Name": "B", "Age": 25}

])

Q9 LOC AND ILOC

loc:

Label-based selection.

iloc:

Integer-position-based selection.

Examples:

df.loc[0]

df.loc[0, "Name"]

df.loc[:, "Name"]

df.loc[0:2, ["Name", "Age"]]

df.iloc[0]

df.iloc[0, 1]

df.iloc[:, 0]

df.iloc[0:2, 0:2]

Important:

  • loc slicing includes the ending label when applicable.
  • iloc slicing excludes the ending position.

Q10 FILTERING DATA

Single condition:

df[df["Age"] > 25]

Multiple conditions:

df[

(df["Age"] > 25) &

(df["Salary"] > 30000)

]

OR condition:

df[

(df["Age"] < 25) |

(df["Salary"] > 35000)

]

NOT condition:

df[~(df["Age"] > 25)]

isin:

df[df["Name"].isin(["Amit", "Ravi"])]

between:

df[df["Age"].between(20, 30)]

query:

df.query("Age > 25")

Q15 MISSING VALUES

Missing values can appear as:

NaN

None

NaT

Check missing values:

df.isnull()

df.isna()

df.notnull()

df.notna()

Count missing values:

df.isnull().sum()

Remove missing rows:

df.dropna()

Remove rows where all values are missing:

df.dropna(how="all")

Fill missing values:

df.fillna(0)

Fill one column:

df["Age"] = df["Age"].fillna(

df["Age"].mean()

)

Other filling methods:

df.ffill()

df.bfill()

ffill:

  • Uses previous valid value.

bfill:

  • Uses next valid value.

Q16 APPLY, MAP AND APPLYMAP

map():

  • Used mainly on Series to transform values.

df["Name"].map(str.upper)

apply():

Applies a function to a Series or DataFrame axis.

df["Salary"].apply(lambda x: x * 2)

df.apply(sum, axis=0)

applymap():

Older DataFrame-wide element-wise function.

Deprecated in modern Pandas.

Prefer df.map() for element-wise DataFrame mapping

in versions that support it.

Q17 GROUPBY

Other operations:

df.groupby("Department").min()

df.groupby("Department").size()

Multiple aggregations:

df.groupby("Department").agg({

"Salary": ["sum", "mean", "max"],

"Age": ["min", "max"]

})

Q19 CONCAT, MERGE AND JOIN

concat:

Combines DataFrames along rows or columns.

pd.concat([df1, df2], axis=0)

pd.concat([df1, df2], axis=1)

merge:

Combines DataFrames using common columns or keys.

pd.merge(
        df1,
        df2,
        on="ID",
        how="inner"
    )

join:

Commonly joins DataFrames using indexes.

df1.join(df2)

Types of joins:

inner:

Only matching records.

left:

All left records and matching right records.

right:

All right records and matching left records.

outer:

All records from both sides.
