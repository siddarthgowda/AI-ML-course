1. Python basics

1 What is Python?

Definition: Python is a high-level, interpreted, object-oriented programming language known for easy-to-read syntax. It is used in web development, data analysis, AI/ML, scientific computing, and more.

2 What are the features of Python?

Easy to read · interpreted · dynamic typing · indentation-based blocks · large standard library · portable · supports OOP · good for scripting and ML.

3 What is dynamic typing in Python?

Definition: Python decides the data type of a variable at runtime. You do not declare the type. The same name can later point to a different type. The type belongs to the value, not permanently to the name.

4 How do we check the data type of a variable?

Use type(x). Example: type(10) → int, type("hi") → str.

5 What are the different data types in Python?

TypeMeaning
intWhole numbers
floatDecimal numbers
strText
boolTrue / False
listOrdered mutable collection
tupleOrdered immutable collection
setUnique unordered collection
dictKey–value pairs
frozensetImmutable set

6 What is type casting?

Definition: Converting a value from one data type to another using int(), float(), str(), bool(), list(), tuple(), set().

7 What is the difference between mutable and immutable data types?

Mutable can change after creation: list, set, dict.

Immutable cannot change: int, float, str, tuple, frozenset.

8 What is indentation in Python?

Spaces/tabs at the start of a line that define a block of code (under if, loops, functions, classes).

9 What is the purpose of indentation?

To show which statements belong together. Wrong indentation causes IndentationError.

10 What is case sensitivity in Python?

Python treats uppercase and lowercase as different. name, Name, and NAME are three different names.

11 What is the difference between syntax and semantics?

Syntax = rules of writing valid code.

Semantics = meaning / what the code does when it runs.

12 What is infinity in Python?

You can use float('inf') and float('-inf') for positive and negative infinity.

13 What is nesting in Python?

Putting one structure inside another: nested if, nested loops, list of lists, dict of dicts.

14 What is loop nesting?

A loop inside another loop. The inner loop runs fully for each outer iteration.

2. Conditional statements and operators

15 What are conditional statements?

Statements that run different blocks depending on whether conditions are true or false. Python uses if / elif / else with indentation.

16 What is if?

if runs a block when its condition is True.

17 What is elif?

elif (else if) checks another condition when earlier if/elif were false.

18 What is else?

else runs when none of the previous conditions were true. No condition of its own.

19 What is the difference between if, elif, and else?

if = first check · elif = more checks · else = fallback when all failed.

20 What are logical operators?

and, or, not — combine or reverse Boolean conditions.

21 What is the difference between and and or?

and → True only if both sides are true.

or → True if at least one side is true.

22 What is the not operator?

not reverses a Boolean: not True → False.

23 How do we use multiple conditions in Python?

Combine with and / or, or chain if / elif / else.

3. Strings

24 What is a string in Python?

A sequence of text characters written in quotes: 'Hello' or "Hello".

25 Is a string mutable or immutable?

Immutable. Methods return a new string; they do not change the original.

26 What is string indexing?

Access one character by position: s[0] is first, s[-1] is last.

27 What is negative indexing?

Counting from the end: -1 last, -2 second last.

28 What is string slicing?

Take a piece: s[start:stop] (stop not included), optional step s[::2].

29 What are string methods?

Built-in helpers like upper(), lower(), strip(), split(), replace(), find(), join().

30 What is the difference between split() and join()?

split() turns a string into a list of parts.

join() joins a list of strings into one string.

31 What is string formatting?

Inserting variables/values into a string in a readable way.

32 What is an f-string?

A string with f prefix that can embed expressions in { }: f"Hi {name}".

33 What are the different ways of formatting strings?

1) f-strings 2) str.format() 3) % formatting (%s, %d, %f). Prefer f-strings.

34 How do we use f-strings with variables?

name = "Rahul"; age = 22; print(f"My name is {name} and my age is {age}")

35 How do we format decimal values using f-strings?

price = 99.567; print(f"Price: {price:.2f}") → 99.57

4. Lists

36 What is a list in Python?

An ordered, mutable collection that can hold mixed types, written with [].

37 Is a list mutable or immutable?

Mutable — you can change, add, remove items.

38 What is positive indexing?

Index from the start: 0, 1, 2, ...

39 What is negative indexing?

Index from the end: -1, -2, ...

40 What is list slicing?

lst[start:stop:step] returns a sublist.

41 What is the difference between append() and extend()?

append(x) adds one item at the end.

extend(iterable) adds each item from another iterable.

42 What is the difference between remove() and pop()?

remove(value) deletes the first matching value (no return of useful index).

pop(index) removes by index and returns the item.

43 What is the difference between sort() and sorted()?

list.sort() sorts in place, returns None.

sorted(iterable) returns a new sorted list.

44 How do we increase every element in a list by 10?

Loop, or comprehension: [i + 10 for i in nums], or with NumPy: arr + 10.

45 What is a nested list?

A list that contains other lists: [[1, 2], [3, 4]].

46 How do we iterate through a list?

for item in my_list: or for i, item in enumerate(my_list):

47 How do we copy a list?

lst.copy(), lst[:], or copy.copy(lst). For nested lists use copy.deepcopy if needed.

5. Tuples

48 What is a tuple?

An ordered collection written with (). It is immutable.

49 Is a tuple mutable or immutable?

Immutable.

50 How do we create a tuple?

t = (10, 20) or t = 10, 20. Single item needs a comma: (5,).

51 What is tuple indexing?

Same as lists: t[0], t[-1].

52 What is tuple slicing?

Same idea: t[1:3].

53 What is the difference between a list and a tuple?

List = mutable []. Tuple = immutable (). Use tuple for fixed groups of values.

54 What are the advantages of tuples?

Safer when data must not change · can be dict keys if elements are hashable · slightly lighter · clear signal of fixed data.

6. Sets

55 What is a set in Python?

An unordered collection of unique hashable items, written with { } or set().

56 Is a set mutable or immutable?

A normal set is mutable. A frozenset is immutable.

57 What is the difference between a list, tuple, and set?

List: ordered, mutable, duplicates OK.

Tuple: ordered, immutable, duplicates OK.

Set: unordered, unique, mutable (unless frozenset).

58 What is union in sets?

All items from both sets: a | b or a.union(b).

59 What is intersection in sets?

Items in both: a & b or a.intersection(b).

60 What is difference in sets?

Items in a but not in b: a - b.

61 What is symmetric difference?

Items in either set but not both: a ^ b.

62 What is the difference between remove() and discard()?

remove(x) raises error if missing.

discard(x) does nothing (no error) if missing.

63 What is pop() in sets?

Removes and returns an arbitrary element (sets are unordered).

64 What is a frozenset?

An immutable version of a set. Cannot add/remove. Can be a dict key if elements are hashable.

65 What is the difference between a set and a frozenset?

Set mutable; frozenset immutable. Only frozenset can be a dict key.

66 How do we remove duplicate values from a list?

list(set(my_list)) (order may change) or preserve order with list(dict.fromkeys(my_list)).

7. Dictionaries

67 What is a dictionary in Python?

A mutable mapping of key → value pairs, written with { }.

68 How does a dictionary store data?

As unique keys mapped to values. Access is by key, not by position.

69 What are keys and values?

Key = label used to look up. Value = data stored under that key.

70 Are dictionaries mutable or immutable?

Mutable. Keys must be hashable (immutable types).

71 How do we access dictionary values?

d["name"] or d.get("name", default).

72 How do we add new key-value pairs?

d["city"] = "Mumbai" — new key adds a pair.

73 How do we update dictionary values?

Assign to an existing key: d["age"] = 23, or d.update({...}).

74 What is the difference between keys(), values(), and items()?

keys() → keys · values() → values · items() → (key, value) pairs.

75 How do we iterate through a dictionary?

for k in d: · for v in d.values(): · for k, v in d.items():

76 What is dictionary nesting?

A value that is another dict (or list of dicts): student["marks"]["Python"].

77 What is the difference between get() and accessing a key directly?

d[key] raises KeyError if missing.

d.get(key) returns None / default — no error.

78 What is the difference between pop() and popitem()?

pop(key) removes a specified key and returns its value.

popitem() removes and returns an arbitrary (key, value) pair (last inserted in modern Python).

8. Loops

79 What is a loop in Python?

Code that repeats: either over items (for) or while a condition is true (while).

80 What is a for loop?

Walks each item of an iterable: for i in items:

81 What is a while loop?

Repeats while a condition stays True. You must update the condition or use break.

82 What is the difference between for and while?

for = known collection/count. while = keep going until a condition fails.

83 What is a nested loop?

A loop inside another loop.

84 What is the break statement?

Leaves the nearest loop immediately.

85 What is the continue statement?

Skips the rest of this iteration and goes to the next.

86 What is the pass statement?

A no-op placeholder when a block is required syntactically.

87 What is the difference between break, continue, and pass?

break exit loop · continue skip this round · pass do nothing.

88 What is indentation in loops?

The loop body must be indented under for/while.

89 How do we iterate through lists, tuples, sets, and dictionaries?

All work with for x in collection:.

Dict default = keys; use .values() / .items() for values/pairs.

9. Functions

90 What is a function in Python?

A reusable block of code that performs a specific task.

91 Why do we use functions?

Avoid repeating code · organize logic · reuse · easier testing.

92 What are the advantages of functions?

Reusability · readability · modularity · less duplication.

93 What is the difference between a built-in function and a user-defined function?

Built-in: provided by Python (print, len, sum).

User-defined: you create with def.

94 What are parameters and arguments?

Parameter = name in the definition. Argument = value passed when calling.

95 What is a positional argument?

Matched to parameters by order.

96 What is a keyword argument?

Passed as name=value, matched by name.

97 What is a default argument?

A parameter value used when the caller skips that argument.

98 What is a variable-length argument?

Accepting any number of arguments using *args and/or **kwargs.

99 What is *args?

Collects extra positional arguments into a tuple.

100 What is **kwargs?

Collects extra keyword arguments into a dictionary.

101 What is the difference between *args and **kwargs?

*args → tuple of positional. **kwargs → dict of keywords.

102 Can we use *args and **kwargs together?

Yes. Write *args before **kwargs. Call with positional first, then keywords.

103 What is a return statement?

Sends a value back to the caller so it can be stored or reused.

104 What is the difference between print() and return?

print displays on screen. return gives a value back to the program.

105 What is a lambda function?

A small anonymous function: lambda args: expression. One expression only.

106 What are the categories of functions in Python?

Built-in · user-defined · lambda · recursive (and methods inside classes).

107 What is recursion?

A function that calls itself. Needs a base case to stop.

108 What is an anonymous function?

A function without a formal def name — typically a lambda.

109 What is the difference between a parameter and an argument?

Parameter in definition; argument at call time.

10. Important Python functions and methods

110 What is map()?

map(fn, iterable) applies fn to every element. Wrap in list() to see values.

111 What is filter()?

filter(fn, iterable) keeps items where fn is True.

112 What is sorted()?

Returns a new sorted list. reverse=True for descending.

113 What is the difference between sort() and sorted()?

sort() in-place on a list. sorted() new list from any iterable.

114 What is zip()?

Pairs items from multiple iterables by position. Stops at the shortest.

115 What is enumerate()?

Gives (index, value) while looping. enumerate(x, start=1) optional.

116 What is min()?

Smallest value among args or in an iterable.

117 What is max()?

Largest value.

118 What is sum()?

Adds numbers in an iterable.

119 What is len()?

Number of items (or characters in a string).

120 What is range()?

Sequence of integers: range(stop) or range(start, stop, step).

121 What is the difference between map() and filter()?

map transforms every item. filter selects some items.

11. Comprehensions

122 What is list comprehension?

Short way to build a list: [expr for i in iterable].

123 What is set comprehension?

{expr for i in iterable} — unique values.

124 What is dictionary comprehension?

{key: value for i in iterable}.

125 Why do we use comprehensions?

Shorter, clearer than many small loops for building collections.

126 What is the difference between a normal loop and list comprehension?

Loop: multi-line, flexible.

Comprehension: one expression-focused line to build a collection.

127 How do we use conditions inside comprehensions?

Filter: [i for i in nums if i > 5].

If/else expression before for: [i+10 if i>5 else i for i in nums].

128 How do we create a new list by increasing every element by 10?

[i + 10 for i in nums]

12. Copying in Python

129 What is copying in Python?

Making another object that holds the same data, instead of two names pointing to one object.

130 What is shallow copy?

New outer object, but nested mutable objects are shared. copy.copy().

131 What is deep copy?

New outer object and copies of nested objects. copy.deepcopy().

132 What is the difference between shallow copy and deep copy?

Shallow: nested shared → changing nested affects original.

Deep: nested independent.

133 What is the copy module?

import copy — provides copy() and deepcopy().

134 What is copy.copy()?

Creates a shallow copy.

135 What is copy.deepcopy()?

Creates a deep copy.

136 How do nested lists behave during shallow copying?

Inner lists are the same objects in original and copy.

137 Why does changing a nested element in a shallow copy affect the original list?

Because both share the same inner list reference.

138 Why does deep copy not affect the original list?

Because nested objects were copied too; they are separate.

13. Exception handling

139 What is an error in Python?

A problem that stops normal execution — syntax problems or runtime problems.

140 What is a syntax error?

Invalid code structure detected before/at parse time. Usually must be fixed before running; not caught by normal try/except on the same bad line.

141 What is an exception?

A runtime error that interrupts the program’s normal flow.

142 What is the difference between a syntax error and an exception?

Syntax error = invalid code writing.

Exception = valid syntax, fails while running (e.g. divide by zero).

143 What are the different types of exceptions?

ValueError, TypeError, ZeroDivisionError, KeyError, IndexError, NameError, FileNotFoundError, and many more.

144 What is try?

Block with code that might raise an exception.

145 What is except?

Block that runs when a matching exception occurs.

146 What is else in exception handling?

Runs if the try block had no exception.

147 What is finally?

Runs whether or not an exception occurred (cleanup).

148 What is the difference between else and finally?

else only on success. finally always.

149 What is the raise keyword?

Manually triggers an exception: raise ValueError("bad input").

150 What is a custom exception?

Your own exception class, usually subclassing Exception.

151 How do we create a custom exception?

class MyError(Exception):
    pass

152 How do we raise a custom exception?

raise MyError("message")

153 What is the difference between raise and except?

raise creates/throws an error. except catches and handles it.

14. Object-Oriented Programming (OOP)

154 What is Object-Oriented Programming?

A style that organizes programs around objects that hold data (attributes) and actions (methods).

155 What is a class in Python?

A blueprint/template for creating objects.

156 What is an object?

An instance of a class.

157 What is the difference between a class and an object?

Class = blueprint. Object = concrete instance created from it.

158 What are attributes?

Variables that store object/class data (properties).

159 What is the purpose of __init__()?

Special method auto-called when an object is created; initializes attributes.

160 What is a constructor?

In Python, typically __init__ — sets up a new object.

161 What is self in Python?

Refers to the current instance. First parameter of instance methods. Not a keyword.

162 What are methods?

Functions defined inside a class — object behaviour.

163 What are the different types of methods?

Instance methods (self) · class methods (@classmethod, cls) · static methods (@staticmethod). Class covered instance methods most.

164 What are the four pillars of OOP?

Encapsulation · Inheritance · Polymorphism · Abstraction.

165 What is encapsulation?

Bundling data and methods, and controlling access to internal details.

166 What is inheritance?

A child class acquires attributes/methods from a parent class.

167 What is polymorphism?

Same interface/name, different behaviour for different types/classes.

168 What is abstraction?

Hiding complex details and showing only what is needed.

169 What are the different types of inheritance?

Single · Multiple · Multilevel · Hierarchical · Hybrid.

170 What is multiple inheritance?

One child inherits from more than one parent.

171 What is multilevel inheritance?

A → B → C chain (grandchild inherits through parent).

172 What is method overriding?

Child class defines a method with the same name as the parent, replacing behaviour.

173 What is method overloading?

Same method name, different parameter lists. Python does not support classic overloading; use defaults/*args instead.

174 What is MRO (Method Resolution Order)?

The order Python searches for methods with multiple inheritance. See ClassName.mro().

175 What are access modifiers?

Conventions for visibility: public, protected (_name), private (__name name-mangling).

176 What is the difference between public, protected, and private members?

Public: normal names.

Protected: _name (convention: internal).

Private: __name harder to access from outside.

177 What is variable scope?

Where a name is visible: local (inside function) vs global (module level).

178 What is the difference between variable scope and access modifiers?

Scope = where a name exists (local/global).

Access modifiers = OOP visibility of class attributes/methods.

15. MongoDB

179 How do we write MongoDB queries?

In the mongo shell / drivers: db.collection.find(query, projection). Filters use documents like { age: { $gt: 18 } }.

180 How do we use find()?

db.students.find({ course: "Python" }) returns matching documents. findOne() for a single doc.

181 How do we use aggregation?

db.collection.aggregate([ stage1, stage2, ... ]) — pipeline of stages that transform documents.

182 How do we use $project?

Stage to include/exclude/reshape fields: { $project: { name: 1, _id: 0 } }.

183 How do we use $unwind?

Deconstructs an array field into one document per array element.

184 How do we use $group?

Groups docs by a key and can compute sums/counts/avgs: { $group: { _id: "$city", total: { $sum: 1 } } }.

16. Python & OOPs (extra sheet)

185 What are OOPs methods?

Ans: Methods are functions defined inside a class. They are used to perform operations on objects or classes.

There are 3 main types of methods:

  1. Instance Method → Uses self to access object data.
  2. Class Method → Uses cls to access class data.
  3. Static Method → Does not require self or cls.

186 What are the four pillars of OOPs?

Ans:

  1. Encapsulation → Bundle data and methods in a class; control access to prevent unintended changes.
  2. Inheritance → Child class acquires parent properties and methods (code reuse).
  3. Polymorphism → One interface or name, different behaviours by object or type.
  4. Abstraction → Hide implementation; show only essential features.

187 What is File Handling in Python?

Ans: File handling is the process of creating, opening, reading, writing, appending and closing files using Python.

It helps us store data permanently.

Common file modes:

ModeMeaning
rRead
wWrite
aAppend
xCreate
r+Read and Write
w+Write and Read
a+Append and Read

188 What is a Context Manager?

Ans: A context manager is a feature in Python that manages resources automatically and ensures proper cleanup after their use.

191 What is an Abstract Class?

Ans: An abstract class is a class that cannot be instantiated directly when it contains unimplemented abstract methods.

It acts as a blueprint for child classes.

Python uses ABC and @abstractmethod.

from abc import ABC, abstractmethod

class Animal(ABC):
    @abstractmethod
    def sound(self):
        pass

class Dog(Animal):
    def sound(self):
        print("Dog barks")

d1 = Dog()
d1.sound()

Python does not have a separate interface keyword. We can achieve interface-like functionality using Abstract Base Classes (ABC) or Protocols.

It defines WHAT a class should do, rather than HOW it should do it.

193 What is the difference between Encapsulation and Abstraction?

Encapsulation:

  1. Wraps data (variables) and methods in one class.
  2. Controls access (public / protected / private).
  3. Prevents unintended modification of data.

Abstraction:

  1. Hides internal implementation details.
  2. Exposes only essential features (data or process abstraction).
  3. Reduces complexity for the user.

Example: Encapsulation → protecting bank account balance. Abstraction → using an ATM without knowing its internal working.

196 What are Public, Private and Protected Access Modifiers?

Ans: Access modifiers indicate how variables and methods are intended to be accessed.

  1. Public → Attributes and methods accessible from anywhere inside or outside the class. Example: self.name
  2. Protected → Intended for the class and subclasses; single underscore _. Outside access is allowed in Python but discouraged. Example: self._department
  3. Private → Intended for use only within the class; double underscore __ triggers name mangling. Example: self.__salary

Note: Python does not strictly enforce public, protected and private access restrictions.

197 Give one structure combining OOP concepts.

from abc import ABC, abstractmethod

class Employee(ABC):
    def __init__(self, name):
        self.name = name
        self._department = "IT"
        self.__salary = 50000

    @abstractmethod
    def work(self):
        pass

    def display(self):
        print(self.name)
        print(self._department)
        print(self.__salary)

class Developer(Employee):
    def work(self):
        print("Developer writes Python code")

class Tester(Employee):
    def work(self):
        print("Tester tests applications")

d1 = Developer("Rahul")
t1 = Tester("Amit")
d1.display()
d1.work()
t1.work()

OOP concepts used:

  1. Encapsulation → Public, Protected and Private variables.
  2. Inheritance → Developer and Tester inherit Employee.
  3. Polymorphism → Both classes implement work() differently.
  4. Abstraction → Employee is an abstract class.

201 What is the difference between Instance Method, Class Method and Static Method?

1. Instance Method:

  • Works with an object.
  • Uses self.
  • Can access instance and class variables.

2. Class Method:

  • Works with the class.
  • Uses cls.
  • Defined using @classmethod.
  • Can access and modify class variables.

3. Static Method:

  • Does not require self or cls.
  • Defined using @staticmethod.
  • Used for independent operations related to the class.
class Student:
    school = "ABC School"

    def instance_method(self):
        print(self.school)

    @classmethod
    def class_method(cls):
        print(cls.school)

    @staticmethod
    def static_method():
        print("Hello Student")
