Core OOP

Part 1: Introduction to OOPs

Q1 What is OOPs?

OOPs stands for Object-Oriented Programming.

It is a programming approach that organizes code using

classes and objects.

Q2 What are the four pillars of OOPs?

  • Inheritance
  • Polymorphism
  • Encapsulation
  • Abstraction

Q3 What are the advantages of OOPs?

  • Code reusability
  • Data organization
  • Easy maintenance
  • Flexibility
  • Scalability
  • Encapsulation

Q4 What is procedural programming?

Procedural programming organizes code using functions

and procedures.

Q5 Difference between procedural programming and OOPs?

Procedural: Focuses on functions.

OOPs: Focuses on classes and objects.

Q6 Does Python support OOPs?

Yes. Python supports classes, objects, inheritance,

polymorphism, encapsulation and abstraction.

Q7 Is Python fully object-oriented?

Python is an object-oriented language, but it also

supports procedural and functional programming.

Q8 Give a real-world example of OOPs.

Class: Car

Objects: BMW, Audi, Toyota

Attributes: Color, model, speed

Methods: Start, stop, accelerate.

Part 2: Class and Object

Q9 What is a class?

A class is a blueprint or template used to create objects.

Q10 What is an object?

An object is an instance of a class.

Q11 Difference between class and object?

Class:

  • Blueprint.
  • Defines attributes and methods.
  • Created using class keyword.

Object:

  • Instance of a class.
  • Has individual data.
  • Created by calling the class.

Q12 How do you create a class?

class Student:
    pass

Q13 How do you create an object?

class Student:
    pass
s1 = Student()

Q14 Can we create multiple objects from one class?

Yes.

s1 = Student()
s2 = Student()
s3 = Student()

Q15 Can multiple objects have different values?

Yes. Each object can have different instance variables.

Q16 What happens when an object is created?

Python creates an instance and calls __init__()

if it is defined.

Q17 Can we create a class without an object?

Yes.

Q18 Can we create an object without a user-defined class?

Yes. Built-in classes such as int, str and list

can create objects.

Q19 What is an instance?

An individual object created from a class.

Q20 What is an attribute?

A variable or property associated with an object or class.

Part 3: Variables in Classes

Q21 What are the types of variables in classes?

  • Instance variable
  • Class variable
  • Local variable

Global variables can also be accessed according to scope rules.

Q22 What is an instance variable?

A variable belonging to an individual object.

Usually defined using self.

class Student:
    def __init__(self, name):
        self.name = name
s1 = Student("Rahul")
s2 = Student("John")
print(s1.name)
print(s2.name)

Output:

Rahul
John

Q23 What is a class variable?

A variable defined inside a class but outside

instance methods. It is shared at class level.

class Student:
    school = "ABC"
print(Student.school)

Q24 Difference between instance and class variables?

Instance variable:

  • Belongs to individual object.
  • Usually uses self.
  • Each object can have a different value.

Class variable:

  • Belongs to the class.
  • Shared at class level.
  • Access using class name or object.

Q25 What is a local variable?

A variable declared inside a function or method.

Q26 What is a global variable?

A variable declared outside functions and classes.

Q27 What is variable shadowing?

When a variable in an inner scope has the same name

as a variable in an outer scope.

Q28 Can we modify a class variable using an object?

Yes, but assigning through an object normally creates

an instance attribute instead of changing the class variable.

Q29 How do we modify a class variable?

class Student:
    school = "ABC"
Student.school = "XYZ"

Part 4: Self, Cls and Super()

Q30 What is self?

self refers to the current object of the class.

Q31 Is self a keyword?

No. It is a naming convention.

Q32 Can we use another name instead of self?

Yes, but self is the standard convention.

Q33 What is cls?

cls refers to the current class.

Q34 Difference between self and cls?

self = Current object.

cls = Current class.

Q35 What is super()?

super() is used to access the next class in MRO,

commonly used to call parent class functionality.

class Parent:
    def display(self):
        print("Parent")
class Child(Parent):
    def display(self):
        super().display()
        print("Child")
obj = Child()
obj.display()

Output:

Parent
Child

Q36 Can we use super() in multiple inheritance?

Yes. It follows MRO.

Q37 What happens if self is missing?

Calling the instance method normally through an object

usually causes TypeError if the method does not accept

the automatically passed object.

Part 5: Methods in Python

Q38 What is a method?

A function defined inside a class.

Q39 What are the three main types of methods?

  • Instance method
  • Class method
  • Static method

Q40 What is an instance method?

A method that works with instance data and uses self.

Q41 What is a class method?

A method that works with class-level data and uses cls.

It uses @classmethod.

Q42 What is a static method?

A method that does not automatically receive self or cls.

It uses @staticmethod.

Q43 Difference between three methods?

Instance method:

  • Uses self.
  • Accesses instance data.

Class method:

  • Uses cls.
  • Accesses class data.

Static method:

  • No automatic self or cls.
  • Used for utility operations.

Q44 Can we call static methods using objects?

Yes.

Q45 Can class methods access instance variables directly?

No. They need an object to access instance data.

Q46 Can we create multiple methods in one class?

Yes.

Q47 Can one method call another method?

Yes, using self for instance methods.

Part 6: Constructor and Destructor

Q48 What is a constructor?

A special initialization mechanism used when an object

is created.

Q49 What is __init__()?

An initializer automatically called after object creation.

class Student:
    def __init__(self):
        print("Constructor called")
s1 = Student()

Q50 What are the types of constructors?

  • Non-parameterized constructor.
  • Parameterized constructor.

Q51 What is a default constructor?

A constructor that does not require additional

user-defined arguments.

Q52 What is a parameterized constructor?

A constructor that accepts arguments to initialize

object attributes.

class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age
s1 = Student("Rahul", 25)

Q53 Does Python support constructor overloading?

Not traditional constructor overloading.

We can simulate it using default arguments, *args,

or class methods.

Q54 Can we define multiple __init__ methods?

No. The last definition replaces earlier definitions.

Q55 What is a destructor?

A finalizer used for cleanup when an object is finalized.

Q56 What is __del__()?

A special finalizer method.

Q57 Difference between constructor and destructor?

__init__() = Initializes an object.

__del__() = Performs finalization.

Q58 Difference between del and __del__()?

del = Deletes a reference or attribute.
__del__() = Finalizer method.

Q59 Is __del__() guaranteed to execute?

No. Its execution timing is not guaranteed.

Context managers are preferred for resource cleanup.

Inheritance

Q61 What is inheritance?

Inheritance is an Object-Oriented Programming concept in

which a class (child or derived class) acquires the properties

and methods of another class (parent or base class). It promotes

code reusability and allows existing functionality to be extended.

In simple words: Inheritance allows one class to reuse the

properties and methods of another class.

Q62 What are the five types of inheritance?

Type | Definition

Single inheritance | A child class inherits from one parent class.

Multiple inheritance | A child class inherits from two or more parent classes.

Multilevel inheritance | A class inherits from another derived class, forming an inheritance chain.

Hierarchical inheritance | Two or more child classes inherit from the same parent class.

Hybrid inheritance | A combination of two or more types of inheritance.

Q63 What is single inheritance?

One child class inherits from one parent class.

class Parent:
    def show(self):
        print("Parent")
class Child(Parent):
    pass
obj = Child()
obj.show()

Q64 What is multiple inheritance?

One child class inherits from multiple parent classes.

class Father:
    def show1(self):
        print("Father")
class Mother:
    def show2(self):
        print("Mother")
class Child(Father, Mother):
    pass

obj = Child()

obj.show1()

obj.show2()

Q65 What is multilevel inheritance?

Inheritance across multiple levels.

class A:
    pass
class B(A):
    pass
class C(B):
    pass

Q66 What is hierarchical inheritance?

Multiple child classes inherit from one parent.

class Parent:
    pass
class Child1(Parent):
    pass
class Child2(Parent):
    pass

Q67 What is hybrid inheritance?

Combination of two or more inheritance types.

Q68 Difference between single and multiple inheritance?

Single = One parent.
Multiple = Multiple parents.

Q69 Difference between multilevel and hierarchical?

Multilevel = Multiple inheritance levels.
Hierarchical = Multiple children share one parent.

Q70 What is method overriding?

Child class provides its own implementation of an

inherited method.

Q71 Why use method overriding?

To customize parent class behavior.

Q72 Can we override constructors?

Yes. A child class can define its own __init__().

Q73 Does the parent constructor execute automatically if the child defines its own constructor?

No. Use super().__init__() when required.

Q74 What is the diamond problem?

A multiple inheritance situation where a class has

multiple inheritance paths to a common parent.

Q75 What is MRO?

Method Resolution Order determines the order in which

Python searches classes for methods and attributes.

Q76 How to check MRO?

print(ClassName.mro())
print(ClassName.__mro__)

Q77 Difference between super() and directly calling parent?

super() follows MRO and supports cooperative

multiple inheritance. Direct parent calls do not.

Polymorphism

Q78 What is polymorphism?

Polymorphism is an Object-Oriented Programming concept that

allows a single interface, method, or operator to represent

different behaviours depending on the object or data type with

which it is used.

In simple words: Polymorphism means one name or interface can

have different behaviours.

Q79 What are common forms of polymorphism?

Type | Definition

Method overriding | A child class provides its own implementation of a method inherited from its parent class.

Method overloading | Multiple methods share the same name with different parameter lists. Python does not support traditional signature-based overloading directly, but similar behaviour can be achieved using default arguments and *args.

Operator overloading | The same operator performs different operations depending on the operand types or custom class implementation.

Duck typing | Python allows objects to be used based on the methods and behaviour they support rather than their specific class.

Q80 What is method overloading?

Multiple methods share the same name with different parameter

lists. Python does not support traditional signature-based

overloading directly, but similar behaviour can be achieved using

default arguments and *args.

Q81 How can we simulate method overloading?

Using default arguments, *args and **kwargs.

Q82 Difference between overloading and overriding?

Overloading = Same name with different parameters.

Overriding = Child redefines inherited method.

Q83 What is operator overloading?

Giving special behavior to operators for custom objects.

Q84 Give an example of operator overloading.

class Number:
    def __init__(self, value):
        self.value = value
def __add__(self, other):
        return self.value + other.value
n1 = Number(10)
n2 = Number(20)
print(n1 + n2)

Output:

30

Q85 What is duck typing?

Python focuses on an object's behavior rather than

its actual class or type.

Q86 What is runtime polymorphism?

Method behavior is determined at runtime based on

the actual object.

Q87 What is compile-time polymorphism?

Polymorphism resolved during compilation, such as

traditional method overloading in Java.

Encapsulation

Q88 What is encapsulation?

Encapsulation is an Object-Oriented Programming concept in

which data (variables) and the methods (functions) that operate on

that data are bundled together into a single unit called a class.

It also provides controlled access to the data to prevent

unintended modification.

In simple words: Encapsulation means wrapping data and methods

together inside a class and controlling access to that data.

Q89 Why use encapsulation?

  • Protect internal data from accidental changes.
  • Control data modification.
  • Improve code organization.
  • Maintain data consistency.

Q90 What are access modifiers in Python?

  • Public
  • Protected
  • Private

Q91 What is a public variable?

Public members are attributes and methods that can be

accessed from anywhere in the program, both inside and outside

the class.

Syntax: No underscore prefix. Example: self.name

Q92 What is a protected variable?

Protected members are attributes and methods intended to be

accessed within the class and its subclasses. They are also

accessible from outside the class in Python, but doing so is

discouraged by convention.

Syntax: A single underscore (_) before the variable name.

Example: self._department

Q93 What is a private variable?

Private members are attributes and methods that are intended

to be used only within the class. In Python, a double underscore

triggers name mangling, which changes the attribute's internal

name to reduce accidental access.

Syntax: Double underscore (__) before the variable name.

Example: self.__salary

Q94 Does Python support strict private access?

No. Python uses naming conventions and name mangling.

Q95 What is name mangling?

Double-underscore attributes are renamed internally

using the class name.

Example:

  • self.__salary

Becomes approximately:

  • self._Student__salary

Q96 What is a getter?

A method used to retrieve an attribute value.

Q97 What is a setter?

A method used to modify an attribute value.

Q98 What is @property?

It allows us to access a method like an attribute.

Q99 Difference between public, protected and private?

Public = name

Protected = _name

Private = __name

Abstraction

Q100 What is abstraction?

Abstraction is an Object-Oriented Programming concept that

hides the internal implementation details of an object and exposes

only the essential features or functionality to the user.

In simple words: Abstraction means hiding how something works

internally and showing only what is necessary to use it.

Types of abstraction:

  • Data abstraction — Hides the internal representation of data
  • and exposes only the necessary operations to access or
  • manipulate it.
  • Process abstraction — Hides the internal steps or
  • implementation of a process and exposes only the operation
  • required to perform it.

Q101 Why use abstraction?

To reduce complexity and define common interfaces.

Q102 What is an abstract class?

A class that can define abstract methods which

concrete subclasses must implement.

Q103 What is an abstract method?

A method declared using @abstractmethod.

Q104 Can we create an object of an abstract class?

Not while unresolved abstract methods remain.

Q105 What is the abc module?

Q315 METACLASS METHODS

__new__():

Creates the class object.

__init__():

Initializes the class object.

__call__():

Controls what happens when the class

  • is called to create an instance.

Q316 METACLASS VS CLASS

Class:

Creates objects.

Metaclass:

Creates classes.

Normal class:

  • Defines object behavior.

Metaclass:

  • Defines class creation behavior.

Use cases:

Frameworks, class validation, registration,

  • automatic class modification and ORMs.
