Topic 1: Python Introduction

1 What is Python?

Python is a high-level, interpreted, general-purpose
programming language. It is easy to read and understand.

2 What are the features of Python?

  • Easy to learn
  • High-level language
  • Interpreted execution model
  • Dynamically typed
  • Object-oriented
  • Platform independent
  • Open-source
  • Large standard library

3 Why is Python called a high-level language?

Because its syntax is close to human language and developers
do not need to manage low-level hardware operations directly.

4 Is Python compiled or interpreted?

Python is commonly called an interpreted language.
In CPython, source code is first compiled into bytecode,
which is executed by the Python virtual machine.

5 What is an interpreter?

An interpreter is a program that executes code.

6 Difference between compiler and interpreter?

Compiler:
- Translates source code before execution.
- Commonly generates machine code or another target form.

Interpreter:
- Executes code through an execution environment.
- Runtime errors can occur during execution.

7 What is indentation?

Indentation means spaces at the beginning of a line.
Python uses indentation to define code blocks.

8 What happens if indentation is incorrect?

Python may raise IndentationError or another syntax error.

9 What are comments?

Comments are notes in code that are ignored during
normal execution.

Example:
# This is a comment

10 What is PEP 8?

PEP 8 is the Python style guide that defines coding
conventions and improves code readability.

11 Is Python case-sensitive?

Yes. Name and name are treated as different identifiers.

12 What is the difference between input() and print()?

input()  - Receives input from the user.
print()  - Displays output to the user.

13 What is the use of input()?

It receives user input and returns it as a string.

14 What is the use of print()?

It displays information on the screen.

Topic 2: Variables And Constants

15 What is a variable?

A variable is a name that refers to an object in memory.
It is used to store and access data.

16 How do you declare a variable?

By assigning a value using the assignment operator.

Example:

x = 10

17 What are variable naming rules?

  • Must start with a letter or underscore.
  • Cannot start with a number.
  • Can contain letters, numbers and underscores.
  • Spaces are not allowed.
  • Keywords cannot be used.
  • Names are case-sensitive.

18 What is multiple assignment?

Assigning values to multiple variables in one statement.

Example:
a, b, c = 10, 20, 30

19 How do you assign the same value to multiple variables?

a = b = c = 100

20 What is a constant?

A constant is a value intended not to change.
Python does not strictly enforce constants.
Uppercase names are used by convention.

Example:

PI = 3.14

21 What is dynamic typing?

Python determines the data type of an object at runtime.
A variable can refer to objects of different types.

Example:

x = 10
x = "Python"

22 What is type casting?

Converting one data type into another.

Types:
1. Implicit type conversion
2. Explicit type conversion

23 Difference between implicit and explicit conversion?

Implicit:
Python performs conversion automatically in supported
operations.

Explicit:
Developer manually converts using functions such as

int(), float(), str() and bool().

24 What is type()?

Returns the exact type of an object.

Example:

print(type(10))

Output:
<class 'int'>

25 What is isinstance()?

Checks whether an object belongs to a particular class
or its subclass.

Example:

print(isinstance(10, int))

Output:
True

26 Difference between type() and isinstance()?

type()       - Checks exact type.
isinstance() - Checks class and subclass compatibility.

27 What is id()?

Returns an object's identity, which remains constant
during the object's lifetime.

28 What are common type conversion functions?

int()
float()
str()
bool()
list()
tuple()
set()
dict()
complex()

29 Output-based question:

x = 10
y = x
x = 20

print(x)
print(y)

OUTPUT:

20
10

EXPLANATION:

Reassigning x does not change the object referred to by y.

Topic 3: Data Types

30 What are data types?

Data types define the kind of value an object represents
and the operations that can be performed on it.

31 What are the main built-in data types?

1. Numeric:
int, float, complex

2. Text:
str

3. Boolean:
bool

4. Sequence:
list, tuple, range

5. Set:
set, frozenset

6. Mapping:
dict

7. Binary:
bytes, bytearray, memoryview

8. None:
NoneType

32 What is int?

Stores whole numbers without decimal points.

33 What is float?

Stores decimal numbers.

34 What is complex?

Stores real and imaginary numbers.
Python uses j for the imaginary part.

Example:

x = 5 + 3j

35 What is string?

A sequence of characters enclosed in quotes.

36 What is Boolean?

A data type that represents True or False.

37 What is NoneType?

Represents the absence of a value.
Its only value is None.

38 What are mutable data types?

Objects whose contents can be modified after creation.

Examples:
list, dict, set, bytearray

39 What are immutable data types?

Objects whose contents cannot be modified after creation.

Examples:
int, float, complex, str, tuple, bool,
frozenset, bytes

40 Difference between mutable and immutable?

Mutable - Can be modified after creation.
Immutable - Cannot be modified after creation.

41 Difference between list and tuple?

List:
- Mutable
- Uses []
- Supports modification
- Allows duplicates

Tuple:
- Immutable
- Uses ()
- Does not support element reassignment
- Allows duplicates

42 Difference between set and frozenset?

Set:
- Mutable
- Can add and remove elements

Frozenset:
- Immutable
- Cannot add or remove elements

43 Difference between list, tuple, set and dictionary?

List:
Ordered, mutable, duplicates allowed.

Tuple:
Ordered, immutable, duplicates allowed.

Set:
No positional order, mutable, unique elements.

Dictionary:
Insertion ordered, mutable, key-value pairs,
unique keys.

44 Can a list contain different data types?

Yes.

Example:

data = [10, "Python", 20.5, True]

45 Can a tuple contain a list?

Yes. The tuple is immutable, but its nested list
can still be modified.

46 Can a dictionary have duplicate keys?

No. Duplicate keys overwrite previous values.

47 What are truthy and falsy values?

Truthy values evaluate to True in Boolean conditions.
Falsy values evaluate to False.

Common falsy values:
False, None, 0, 0.0, "", [], (), {}, set()

48 What are binary data types?

bytes - Immutable byte sequence.
bytearray - Mutable byte sequence.
memoryview - Accesses binary data without copying it.

50 What are operators?

operations on variables and values.

  • Bitwise

- Subtraction

// Floor division

// - Floor division, rounds down.

1

55 What are comparison operators?

!= Not equal
> Greater than
< Less than
>= Greater than or equal
<= Less than or equal

56 What are logical operators?

and - Both operands must be truthy.
or - At least one operand must be truthy.
not - Reverses the truth value.

57 Difference between and and or?

and requires both conditions to be True.
or requires at least one condition to be True.

58 What are assignment operators?

=, +=, -=, *=, /=, //=, %=, **=

59 What are membership operators?

in - Checks whether an element exists.
not in - Checks whether an element does not exist.

60 What are identity operators?

is - Checks whether two references point to

         the same object.

is not - Checks whether they point to different objects.

61 Difference between == and is?

== checks value equality.
is checks object identity.

62 What are bitwise operators?

& AND
| OR
^ XOR
~ NOT
<< Left shift
>> Right shift

63 What is operator precedence?

Determines the order in which operators are evaluated.

True behaves like 1 and False behaves like 0
in arithmetic operations.

Topic 5: Conditional Statements

65 What are conditional statements?

Used to execute code depending on whether conditions
are True or False.

66 What are the types?

  • if
  • if-else
  • if-elif-else
  • Nested if
  • Short-hand if
  • Ternary conditional expression

67 What is if?

Executes a block when the condition is True.

68 What is if-else?

Executes one block if True and another if False.

69 What is if-elif-else?

Checks multiple conditions and executes the first
matching branch.

70 What is nested if?

An if statement written inside another if statement.

71 What is a ternary operator?

A one-line conditional expression.

Syntax:

value_if_true if condition else value_if_false

Example:

age = 20
result = "Adult" if age >= 18 else "Minor"

72 Difference between if, elif and else?

if   - First condition.
elif - Additional conditions.

else - Executes when previous conditions are False.

73 Can we use multiple elif statements?

Yes.

74 Can we use if without else?

Yes. Else is optional.

75 What happens if multiple if statements are True?

Separate if statements execute independently.
In an if-elif-else chain, only the first matching
branch executes.

76 What are truthy and falsy conditions?

Truthy values evaluate to True.
Falsy values evaluate to False.

Topic 6: Loops

78 What is a loop?

A loop repeatedly executes a block of code.

79 What are the types of loops?

  • for loop
  • while loop
  • Nested loops

80 What is a for loop?

Iterates over an iterable such as a list, tuple,
string or range.

81 What is a while loop?

Executes repeatedly while the condition is True.

82 Difference between for and while?

for:
- Iterates over an iterable.
- Commonly used to traverse sequences.

while:
- Runs based on a condition.
- Commonly used when repetitions depend on a condition.

83 What is a nested loop?

A loop inside another loop.

84 What is an infinite loop?

A loop that does not terminate because its stopping
condition is never reached.

85 What is range()?

Generates a sequence of integers.

Syntax: 

range(start, stop, step)

86 What are loop control statements?

  • break
  • continue
  • pass

87 What is break?

Immediately terminates the nearest enclosing loop.

88 What is continue?

Skips the remaining statements in the current iteration
and moves to the next iteration.

89 What is pass?

Does nothing. It is used as a placeholder.

90 Difference between break, continue and pass?

break - Exits the loop.
continue - Skips current iteration.
pass - Does nothing.

91 Can we use else with loops?

Yes. The else block executes when the loop finishes
normally, but not when it terminates using break.

92 What is enumerate()?

Returns an index and corresponding value while iterating.

93 What is zip()?

Combines multiple iterables element by element.
By default, stops at the shortest iterable.

94 Difference between range() and enumerate()?

range() generates numbers.
enumerate() provides index and value.

--- Extra study notes ---

300 WHAT IS A GENERATOR

A generator is a special type of iterator that
produces values one at a time.

It uses the yield keyword.

Advantages:

    - Memory efficient.
    - Lazy evaluation.
    - Useful for large datasets.
    - Does not need to store all results at once.

301 NORMAL FUNCTION VS GENERATOR

Normal function:

    def numbers():
        return [1, 2, 3]

Generator function:

    def numbers():
        yield 1
        yield 2
        yield 3

302 YIELD KEYWORD

yield:

    Returns a value and pauses the function.

When the generator is requested again,
execution continues from where it paused.

Example:

    def count():
        yield 1
        yield 2
        yield 3

    for value in count():
        print(value)

Output:

    1
    2
    3

303 NEXT FUNCTION

next() retrieves the next value from an iterator.

    def numbers():
        yield 10
        yield 20
        yield 30

    gen = numbers()

    print(next(gen))
    print(next(gen))
    print(next(gen))

Output:

    10
    20
    30

Calling next() again raises StopIteration.

304 GENERATOR EXPRESSION

Similar to list comprehension,
but uses parentheses.

List comprehension:

    squares = [x*x for x in range(5)]

Generator expression:

    squares = (x*x for x in range(5))

Difference:

List:

    Stores all elements in memory.

Generator:

    Produces elements when requested.

305 ITERATOR VS GENERATOR

Iterator:

    Object that supports __iter__() and __next__().

Generator:

    Convenient way to create an iterator using yield.

Both:

    Support iteration.
    Can be used in for loops.
    Can raise StopIteration.

306 SEND, THROW AND CLOSE

Generator methods:

    next(gen):
        Gets the next value.

    gen.send(value):
        Sends a value into a suspended generator.

    gen.throw(exception):
        Raises an exception inside the generator.

    gen.close():
        Closes the generator.

Advanced topic:

    Understand send(), throw() and close()
    after learning basic yield and next().

307 GENERATOR USE CASES

  • Reading large CSV files.
    - Processing log files.
    - Streaming API results.
    - Processing records one by one.
    - Memory-efficient pipelines.

322 DECORATOR WITH ARGUMENTS

def decorator(func):

        def wrapper(*args, **kwargs):
            print("Before")

            result = func(*args, **kwargs)

            print("After")

            return result

        return wrapper

    @decorator
    def add(a, b):
        return a + b

    print(add(10, 20))

Output:

    Before
    After
    30

*args:

    Accepts positional arguments.

**kwargs:

    Accepts keyword arguments.

323 DECORATOR WITH PARAMETERS

def repeat(times):

        def decorator(func):

            def wrapper(*args, **kwargs):

                for _ in range(times):
                    func(*args, **kwargs)

            return wrapper

        return decorator

    @repeat(3)
    def greet():
        print("Hello")

    greet()

Output:

    Hello
    Hello
    Hello

324 FUNCTOOLS WRAPS

Use functools.wraps to preserve metadata
of the original function.

    from functools import wraps

    def decorator(func):

        @wraps(func)
        def wrapper(*args, **kwargs):
            return func(*args, **kwargs)

        return wrapper

326 PRACTICAL DECORATOR USE CASES

  • Logging
    - Authentication
    - Authorization
    - Execution time measurement
    - Caching
    - Validation
    - Retry logic
    - Access control

Example: Execution time decorator

    import time
    from functools import wraps

    def timer(func):

        @wraps(func)
        def wrapper(*args, **kwargs):

            start = time.perf_counter()

            result = func(*args, **kwargs)

            end = time.perf_counter()

            print("Execution time:", end - start)

            return result

        return wrapper

    @timer
    def calculate():
        return sum(range(100000))

    calculate()
